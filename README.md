# 소서리안 한국어 패치 v1.0.0

메가드라이브 일본판 **Sorcerian**용 비공식 한국어 패치입니다.

## 다운로드

**[패치 다운로드](https://github.com/kilk96/sorcerian-korean-patch/releases/tag/v1.0.0)**에서 `sorcerian-ko-v1.0.0.zip`을 받아 주세요. 비공개 저장소에 접근할 수 있는 계정으로 로그인해야 합니다. 압축을 풀면 패치·설명서·검증 값·글꼴 라이선스가 들어 있습니다. 원본 게임 파일은 직접 준비해 주세요.

## 적용 방법

1. 일본판 원본 ROM과 기존 저장 파일을 백업하고 아래 원본 크기와 SHA-256을 확인해 주세요. 이전 한글판에 덧씌우지 말고 수정되지 않은 원본에 적용해 주세요.
2. **xdelta 3.2.0 이상**을 준비하고 `sorcerian-ko-v1.0.0.xdelta`를 선택해 주세요. 이 패치는 3.2 형식의 파일 검증 기능을 사용하므로 구형 패처에서는 적용되지 않을 수 있습니다.
3. 결과를 원본과 다른 이름의 `.bin` 파일로 저장하고 아래 결과 SHA-256과 비교해 주세요.
4. 결과 파일을 메가드라이브 에뮬레이터에서 새로 실행해 주세요.

Windows PowerShell 명령 예시입니다. 파일명은 준비한 원본에 맞춰 바꾸어 주세요.

```powershell
.\xdelta3.exe -d -s 'Sorcerian (Japan).bin' 'sorcerian-ko-v1.0.0.xdelta' 'Sorcerian_KO_v1.0.0.bin'
Get-FileHash -Algorithm SHA256 -LiteralPath 'Sorcerian_KO_v1.0.0.bin'
```

## 번역·확인 범위

- 메가드라이브판의 10개 시나리오 대사와 주요 메뉴·시설·아이템·몬스터 설명을 한국어로 적용했습니다.
- 이름 입력은 가나다순 자모 선택과 현대 한글 조합을 지원합니다. 한글·영문·숫자를 섞어 최대 11글자로 이름을 지을 수 있습니다.
- 클래스·성별·시설 제목 등 일부 원래 영문은 유지했습니다. 원본 영문·숫자·기호 글꼴도 유지했습니다.
- 사용자 플레이 검수에서 발견한 문제를 반영했습니다. 최신 수정은 한글 높이·이름 목록 순서와 색상·저장/로드 문구입니다.

## 실행과 저장

확인한 환경은 **BizHawk 2.11.1 / Genesis Plus GX**입니다. 일반 플레이 패치이며 검수용 무적·자금 보조나 저장 파일은 포함하지 않습니다.

처음 시작할 때는 새 게임을 권장합니다. 기존 저장을 사용할 때는 백업한 뒤 게임 안의 불러오기를 이용해 주세요. 한글 이름을 보존하기 위해 저장 파일 용량이 확장되어 있으며, 다른 에뮬레이터의 저장 형식은 따로 확인하지 않았습니다. 이전 일본어 이름의 자동 한글 변환은 지원하지 않습니다. 에뮬레이터 순간 저장은 예전 실행 상태를 포함하므로 게임 내 저장과 구분해 주세요.

## 알려진 제한

- 모든 대사·숨은 아이템·조건별 분기를 전수 확인한 것은 아닙니다.
- 일부 원래 영문과 크레디트는 유지했습니다. 사용 여부가 확인되지 않은 원문도 남아 있습니다.
- 실기와 다른 에뮬레이터 환경은 검증하지 않았습니다.

## 지원 원본과 파일 확인

| 항목 | 값 |
|---|---|
| 기종·판본 | Mega Drive / Sorcerian (Japan), 일본 지역 |
| 원본 형식 | 별도 복사기 헤더 없는 선형 바이너리 `.bin` |
| 원본 크기 | 524,288바이트 |
| 원본 SHA-256 | `A8A309A6B03A8C1D4A17B5D809D7ECF56C5A1B2188E2388038797AD632D985C6` |
| 결과 크기 | 1,310,720바이트 |
| 결과 SHA-256 | `4A045FE82EA712C67C8BB8B065B7DD2BB3C4DB94BD15F7BCC1A353B4186AC666` |

SHA-256은 파일 내용이 같은지 확인하는 값입니다. 파일명보다 크기와 이 값이 일치하는지 확인해 주세요. 패치와 포함 파일의 검증 값은 `SHA256SUMS.txt`와 `manifest.json`에 있습니다.

## 문제 제보

패치 버전, 에뮬레이터 이름·버전, 발생 장소와 직전 조작, 문제 화면을 함께 알려 주세요. 원본·패치 적용 완료 게임 파일은 첨부하지 말아 주세요.

## 권리와 글꼴

원작사와 관계없는 팬 번역이며 게임의 권리는 각 권리자에게 있습니다. 글꼴은 **Galmuri7 v2.40.4**를 사용했습니다. 출처와 이용 조건은 `FONT-NOTICE.txt` 및 `LICENSE-Galmuri.txt`를 확인해 주세요.
